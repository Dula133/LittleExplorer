原版参照仍为 `70091609b45fd2b2cf98a5853bfee2d8cbe28991`。

## 可见操作与归属

| 点选对象 | 原生点按效果 | 临时操作（最多两个） |
| --- | --- | --- |
| 原车灯/主前照灯 | 原昼夜切换、原讲解与 MP3 | 灯光档位循环；双闪 |
| 小灯（前位置灯） | 进入小灯档；已为小灯档则关闭 | 灯光档位循环 |
| 左侧前/后橙灯 | LEFT ↔ OFF；另一侧或双闪直接切入 LEFT | 左转开关；双闪 |
| 右侧前/后橙灯 | RIGHT ↔ OFF；另一侧或双闪直接切入 RIGHT | 右转开关；双闪 |
| 原红色尾灯 | 原刹车讲解、增亮、自动恢复 | 无新增入口 |
| 低位前雾灯 | 雾灯开/关 | 雾灯开关 |
| 原雨刮 | 原讲解、13 秒雨天、3 秒延迟雨刮、原截止时序 | 雨量循环；独立雨刮开关 |

档位入口循环：自动 → 小灯 → 前照灯 → 关闭 → 自动。
标签显示请求，第二行显示当前亮灯/电池演示状态；缓动期间允许短暂显示原亮灯状态。
小灯在 POSITION、HEADLIGHT 和原自动/电池点灯时开启；无主照明光束。
雾灯比前照灯低，使用两盏距离 3 场景单位、向下、软边的局部灯，不创建远射光束或雾层。

四个原橙色灯没有复制。前、后灯分别保持在原灯具结构下，只在注册原零件前移入独立子组，
再由 `defPart` 各注册一次。每个灯具/隐形命中代理只有一个归属；红灯继续属于 tail，主灯属于 lights。
新灯具随原场景透视、拆开、装回，新增部件不加入 `SC.order`，常驻图标仍为原 16 个。
首页只构建原预览几何，不增加这些局部灯具，也不接管页面状态接口。

## 临时入口与布局保护

`OBJ.partActions` 为可选场景接口，其他场景不启用。卡片与样式由引擎按需挂载，
不手改生成 HTML，不需要模板例外或二十页机械性改动。
卡片在 `.bottom` 外固定定位，不影响其高度或公共相机适配；每个按钮至少 48px 高、44px 宽。
入口随相关选中对象存在，讲解期间禁用且回调再次检查原 `busy()`，原语音结束后恢复可用。
切换无关零件、模式退出或打开说明页时隐藏。

临时操作反馈可能比原讲解短。操作期间仅保留当前讲解卡的最小高度，防止缩短文本引起
ResizeObserver 重新适配相机；换选或退出后恢复原样。原三大按钮的位置和大小不改。
横屏且零件栏可见、上方空间不足时，卡片放在同一零件栏右侧；临时缩窄可横向滚动的零件栏，
栏高与底部高度保持不变。这是解决局部冲突的调整，不重新设计页面。

## 状态与动画

复用 Phase 1 的 `lighting` / `weather`，没有第二套灯光或天气状态。
小灯、雾灯的实际缓动强度由同一 update 更新，getState 如实报告模型已可用与实际强度。
雾灯在关闭时不加入可见光源列表。转向灯保持单一模式与同一 800ms 时钟，关闭相位禁止选中加亮。
雨量沿用 0/72/180/360 的 InstancedMesh 配置，尺寸不变；无新增动画循环或 setInterval。
显式雨量只接管雨量，显式雨刮只接管雨刮；旧演示期限不能覆盖显式选择。
再次真实点按原雨刮器仍是孩子主动重新启动/停止原演示。

## Phase 3 正式配音缺口

以下新增讲解及反馈未加入 `VOICE_LINES`，也未生成两套正式 MP3。现有系统在非静音时可能
使用系统 TTS 兜底，其可用性依设备而异，不能称为正式配音完成。按钮状态标签本身不额外朗读。
共 20 个新增语音 key，完整清单也保存在候选规则中。原 `tools/check_voice.py` 没有修改，
单独运行仍会按预期报告两个能静态识别的新零件讲解缺音并退出 1。
Phase 2 QA 精确断言只允许这两条静态缺口、另登记动态反馈缺口，同时要求原 295 条映射仍全部被使用，
原 MP3 无缺失/截断且全部解码成功；任何额外缺口均失败，不泛化跳过配音检查。

## 本次实际验收结果

完整主套件为 PASS：22 组检查、165 条原生输入记录，覆盖两种竖屏和两种横屏。
原版行为、Phase 1 API、局部灯具/按钮实际触控、唯一归属、同步闪烁、刹车恢复、
独立天气、拆开装回和十九场景加载均通过。原 598 个 MP3 全部解码，
原车灯两套声音真实播放结束，原车灯/雨刮讲解期间的新按钮锁定与结束后恢复均取证。
新关灯反馈已验证：再次点同侧转向灯显示“转向灯关掉了。”，不再声称正在闪。

原版八张截图的结构、相机、原节点与布局对照通过；所有批准局部区域之外的像素差异为 0。
首页截图完全一致。手机默认画面仅局部新增灯具发生变化（390×844 为 270 像素、
360×800 为 231 像素），没有重录或修改原版证据。
无新增 JS、WebGL 或资源错误；原 `/favicon.ico` 404 仍精确单列为已知原版情况。

另执行 [夜间雾灯取证脚本](qa/simple-plus-phase2/verify-night-fog.cjs)：
通过真实模型点选及 DOM 按钮关闭主灯、小灯，开关雾灯，未直接设置 API/材质。

只代表本次渲染截图，不是现实光度测量。实际局部灯距离为 3，朝下，未创建远射光束。
此补充测试为 PASS，保存开/关截图与独立报告。
