## 接口与状态所有权

`SCENES.car.lighting`：

- `setLampMode('OFF'|'POSITION'|'HEADLIGHT')`：显式接管。POSITION/HEADLIGHT 请求小灯状态，
  但本轮没有小灯模型；只有 HEADLIGHT 点亮原前照灯。
- `useAutomaticLamps()`：撤销手动接管，恢复原启动/昼夜自动显示。
- `setTurnMode('OFF'|'LEFT'|'RIGHT'|'HAZARD')`：四个原橙色灯共用 800ms 周期，各亮/灭 400ms。
  左侧为驾驶员所在的负 Z 侧，前后保持原零件归属，不增加假灯。
- `triggerBrake(duration=3000)`：毫秒，0–60000；复用原 `brakeUntil` 和红灯缓动恢复。
- `setFogLight(boolean)`：仅前雾灯请求状态，本轮无灯具或光束。
- `getState()`：返回独立快照，分别报告请求、来源、目标、实际缓动强度及模型可用性。

没有手动请求时，原前照灯仍随启动/昼夜变化。电池的 3500ms 演示临时优先，
结束后回到最新手动请求或原自动状态；演示中修改请求不会被旧值覆盖。
原车灯点击仍切换昼夜，显式灯光请求继续拥有前照灯控制权。

为逐像素保护原默认画面，转向 API 尚未调用时保留原灯罩的低强度装饰材质
（前 0.2、后 0.35，不代表转向信号开启），状态标记 `turnSource: ORIGINAL_LENS`。
第一次显式调用后标记为 EXPLICIT，OFF 与熄灭相位发光强度为 0；选中也不能加亮。
`blinkOn` 始终报告真实的信号相位。小灯、雾灯分别报告 `positionVisualAvailable:false`、
`fogVisualAvailable:false`，不能把状态支持称为视觉完成。

`SCENES.car.weather`：

- `setRainLevel('NONE'|'LIGHT'|'MEDIUM'|'HEAVY')`：独立于雨刮，清除旧雨量演示期限。
- `setWiperEnabled(boolean)`：独立于雨量，撤销旧雨刮开始/结束期限；本轮仍只有原单一速度。
- `getState()`：报告请求来源、雨量、配置、实际雨滴数量/缓动和雨刮状态；返回配置副本。

| 雨量 | 数量 | 下落速度（场景单位/秒） | 透明度上限 | 阴天强度上限 |
| --- | ---: | --- | ---: | ---: |
| NONE | 0 | 0 | 0 | 0 |
| LIGHT | 72 | 6–8 | 0.45 | 0.3 |
| MEDIUM | 180 | 8–11 | 0.65 | 0.65 |
| HEAVY | 360 | 11–15 | 0.8 | 1 |

共用原 `BoxGeometry(.018,.6,.018)` 和一个容量 360 的 InstancedMesh；不放大雨滴，不新增遮挡层。
保留原构建过程的随机数消耗顺序，避免改变后续首页缩略图的随机造型；只分配 360 份雨滴数组。
NONE 采用原缓动消退，消退过程中 `renderedCount` 与逻辑目标数量可暂时不同，状态分别报告。

原雨刮零件点击仍启动 13 秒降雨、3 秒延迟雨刮、15 秒雨刮截止；再次点击停止降雨，
雨刮保留 1.5 秒后缓动停放。这次明确的原零件点击会重新接管演示；
之后调用雨量 API 仅接管雨量，雨刮 API 仅接管雨刮，旧期限不能反向覆盖请求。
所有动画使用现有 update，不新增 setInterval。状态按场景上下文隔离；首页 build 不接管页面 API。

## 本次实际结果

完整候选 QA 为 PASS：17 组检查、47 条原生触控记录、两套车灯讲解真实播放结束、
598 个原 MP3 解码、首页与其他十九场景加载均通过。新增接口调用单独归类为 API 测试。
浏览器错误为 0；原版自动请求不存在的 `/favicon.ico` 所产生的 404 仍单独记录，不计为新增错误。

八张原版对照中七张的解码像素完全一致，包括首页和三种尺寸的汽车默认画面。
“看里面”截图有 913 个不同像素，最大单通道差值为 2/255，
差异范围为 `[125,746,390,844)`，全部位于底部控件/阴影合成范围；746 行以上差异为 0。
相机、动画时刻、布局与节点快照精确一致；另有 344 个模型节点及几何属性 SHA256、
材质和配置的原版对照通过。此微小差异符合预设舍入阈值，未观察到结构或功能改变，
没有修改原截图或候选截图来消除差异。

实测雨滴数量为 0/72/180/360；小/中/大雨测得下落速度范围分别约为
6.004–7.958、8.006–10.987、11.008–14.993 场景单位/秒。
截图已检查，雨量差别来自密度、速度与原阴天效果，雨滴尺寸保持不变。
