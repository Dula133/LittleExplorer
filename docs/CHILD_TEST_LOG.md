# LittleExplorer 儿童体验测试记录

本文件用于长期记录儿童使用 LittleExplorer 时的行为、原话及由此产生的产品需求。每次测试复制下方模板，按日期追加；保留旧记录，便于比较不同版本的体验。

## 记录规则

- 只记录可观察的动作、界面结果和儿童原话，不评价儿童能力，不生成心理结论。
- 将事实、原话与成人推断分开。没有观察到的项目填写“未观察”；无法确定的填写“未知”。
- 成人的提问、提示或操作帮助应一并记录，以区分主动探索和提示后的行为。
- 儿童原话用引号标记，尽量逐字记录；记不清的内容标为“回忆转述”，不要补写或改成成人表达。
- 时间标明是计时、估计还是未记录；停留时间不作为能力或兴趣的结论。
- 使用匿名测试编号，不记录姓名、联系方式等身份信息。
- 需求是待确认的产品建议。儿童提出的要求和成人观察推断分别登记，并引用对应的观察或原话编号。
